# Course Reader — Introduction (summary)
Source: CPSC 310 course reader, Introduction. Pasted 2026-10-08.

- Software = instructions that consume input, compute, emit output.
- Failures (crash) vs defects (runs but behaves incorrectly).
- Dijkstra 1972: bigger computers → programming a gigantic problem. Systems grow (1 MLOC common; hundreds of MLOC exist). Car electronics/software 16% of cost (1990) → 40% (2015).
- Definitions: programming = "transforming a mental plan of desired actions for a computer into a representation understood by the computer" (Hoc & Nguyen-Xuan). Knuth: explain to humans what we want the computer to do.
- Software engineering = "The establishment and application of scientific, economic, social, and practical knowledge in order to specify, invent, design, build, validate, deploy, maintain, research, and improve software that is correct, reliable, and works efficiently on real machines."
- Programming ≈ only the "build" task.

Reader sidebar (Software Construction): Analytical Code Design → Cost of Change, Change Difficulty, Refactoring, Design Principles, Testability & Test Doubles, Blackbox Testing, Testability – Automatability. Software Design → Design Patterns, Safe Versioning, APIs, Testing Pyramid.
